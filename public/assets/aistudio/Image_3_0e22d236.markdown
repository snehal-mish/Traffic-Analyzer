## Brand & Style
This design system embraces a high-contrast futuristic aesthetic that combines sleek cyberpunk elements with rigorous modern urban infrastructure data-monitoring needs. The interface evokes a sense of absolute precision, real-time control, and high-stakes operations.

Targeting urban planners, autonomous transit dispatchers, and system operators, the UI demands extreme legibility combined with an immersive atmospheric feel. The visual experience is anchored by deep, absorbing dark backgrounds that recede into the void, allowing critical telemetry, alerts, and spatial nodes to pop with luminous clarity. 

Design Style: **High-Contrast / Bold** mixed with **Glassmorphism** for telemetry overlays. The visual hierarchy utilizes razor-sharp edges, translucent glass panels with subtle backdrop blurs, and vibrant glowing neon accents to communicate status instantaneously without fatiguing the operator over long shifts.

## Colors
The color architecture relies on absolute dark zinc and slate foundations to maximize contrast for luminous data points. 

- **Primary:** Neon Cyan (`#00F0FF`) dictates active routing vectors, primary interactive states, and core system telemetry.
- **Secondary:** Emerald Green (`#00FF66`) signals optimal flow, nominal vehicle states, and system success metrics.
- **Tertiary:** Deep Violet (`#220844`) serves as a secondary framing tone for deep analytics and regional sectors.
- **Neutral:** Deep Slate (`#090D16` canvas, `#131B2E` surface containers, `#23324F` borders) structures the dense layout hierarchy.
- **System Feedback:** Dynamic alerts utilize High-Alert Red (`#FF2A5F`) and Caution Amber (`#FFB800`).

## Typography
Typography is split purposefully between geometric authority for structural headers and high-precision monospaced forms for rapid data parsing.

- **Headlines:** *Space Grotesk* provides an engineered, futuristic geometric structure suited for high-level telemetry metrics and dashboard titles.
- **Body & Labels:** *JetBrains Mono* ensures tabular data, coordinate systems, timestamps, and system logs remain perfectly aligned and readable at a glance.

Ensure all numeric data utilizes tabular figures to prevent jitter during live traffic flux updates. Font sizes above 32px must scale down on viewports under 768px.

## Layout & Spacing
The layout relies on a strict **12-column fluid grid** system engineered for dense data displays, multi-monitor operations, and real-time map feeds. 

- **Gutters & Margins:** 16px (`1rem`) gutters separate dense analytical modules, while outer margins scale from 16px on mobile to 24px (`1.5rem`) on desktop.
- **Spacing Rhythm:** Built on an 4px base scale, utilizing tighter gaps (`space-xs`, `space-sm`) inside telemetry readouts and structured spacing (`space-md`, `space-lg`) for card containers.
- **Breakpoints:** Mobile (`< 768px`, single-column stacked telemetry), Tablet (`768px - 1279px`, two-column split view), Desktop (`≥ 1280px`, full multi-panel command center layout).

## Elevation & Depth
Depth is achieved primarily through **Glassmorphism** and low-opacity chromatic layering rather than traditional drop shadows. 

- **Surfaces:** Utilize semi-transparent deep slate surfaces (`#131B2E` at 85% opacity) coupled with high-end backdrop blurs (`blur(16px)`) to establish floating analytical panels over live map feeds.
- **Borders & Glows:** Outer boundaries are defined by "ghost borders" using low-opacity cyan or zinc lines (`1px solid rgba(0, 240, 255, 0.2)`). Active states, warnings, and high-priority cards emanate subtle, diffuse ambient glow vectors (`box-shadow: 0 0 15px rgba(0, 240, 255, 0.15)`) to guide operator focus instantly.

## Shapes
The shape language is strictly **Sharp (0px roundedness)** to reinforce the technical, militaristic, and high-precision aesthetic of an urban AI command system. 

- **Geometry:** All buttons, data cards, input fields, and structural containers feature 0px border radii with crisp, orthogonal intersections. 
- **Accents:** Small technical notches or diagonal corner cutouts (`clip-path`) may be applied selectively to primary frame headers and modal containers to enhance the cyberpunk HUD aesthetic.

## Components
Components are engineered for zero-latency visual confirmation and high-density information architecture.

- **Buttons:** Sharp-edged rectangular blocks with high-contrast text. Primary actions utilize a solid Neon Cyan fill with dark text and a hard glowing outline; secondary actions use transparent backgrounds with a 1px cyan border and glowing hover state.
- **Chips & Tags:** Compact, monospaced status badges with sharp corners, featuring subtle background fills (e.g., emerald green background at 15% opacity with solid green text) to denote vehicle flows or AI confidence levels.
- **Input Fields:** Deep slate backgrounds with 1px zinc borders that shift to solid neon cyan upon focus. Include integrated terminal-style carets and monospaced placeholder text.
- **Checkboxes & Radios:** Sharp square and diamond geometries replacing standard rounded inputs, utilizing bright cyan indicators when toggled active.
- **Cards & Telemetry Panels:** Translucent glassmorphism containers featuring explicit grid coordinates in the header, live status indicator pips, and top-border accent lines indicating module health.
- **Additional Command Elements:** 
  - *Data Sliders:* Segmented track lines with glowing cyan thumb nodes for manual AI intervention thresholds.
  - *Live Feed Viewports:* Embedded video/vector map containers with corner crosshairs and real-time coordinate overlays.
  - *Terminal Logs:* Monospaced scrolling event feeds with color-coded severity levels (Cyan for info, Amber for warnings, Red for system overrides).
